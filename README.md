# Vanilla JavaScript Hex Color Flipper

A clean, interactive single-page web application designed to generate random hexadecimal color codes and apply them dynamically to the UI.

## Key Features
* **Random Hex Generation:** Utilizes a custom array of valid hexadecimal characters and a pseudo-random number generator to build unique 6-digit color codes (`#RRGGBB`).
* **Smooth Transitions:** Implements CSS transitions (`background-color 0.3s ease`) for fluid visual changes when switching colors.
* **Live Code Display:** Instantly updates a monospace text badge to show the active hexadecimal color value.

## Tech
* **Markup & Styling:** HTML5, CSS3 (Flexbox, CSS transitions)
* **Scripting:** Vanilla JavaScript (ES6+, DOM Manipulation)
